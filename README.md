# ポモドーロタイマー & 勉強記録

ブラウザだけで動く、ポモドーロ(集中)タイマーと勉強記録のアプリです。ビルドもサーバーも不要な静的サイト(PWA)で、データはすべて利用者のブラウザ(`localStorage`)に保存されます。

## 機能

- **タイマー**: 集中 / 短い休憩 / 長い休憩。長さ・長い休憩までの回数・自動開始を設定できます。
- **今日の目標**: 1日の目標セット数と進捗。
- **今日のタスク**: 見込みポモドーロ数つき。選んだタスクに集中時間が紐づき、終了予測時刻も表示します。
- **勉強記録**: カレンダー(ヒートマップ)・日ごとのリスト・直近14日のグラフ・連続記録、CSV書き出し。
- **小窓(ピクチャーインピクチャー)**: Chrome / Edge で、別ウィンドウにタイマーを表示。
- **フェーズ終了のお知らせ**: 音・通知(通知は設定画面から許可)。
- **PWA**: ホーム画面に追加でき、オフラインでも動きます。

## 使い方・開発

- `index.html` をブラウザで開くだけで動きます(`file://` では Service Worker が動かないため、オフライン対応と SW 経由の通知は無効です)。
- Service Worker を含めて試すときは静的サーバーで配信します。例: `python3 -m http.server 8000` → http://localhost:8000/
- 公開は GitHub Pages など任意の静的ホスティングで行えます。**`index.html` を更新したら `sw.js` の `CACHE` 名を上げてください**(インストール済みの PWA に新しい版を届けるため)。
- ファイル構成: `index.html`(画面・スタイル・ロジックをすべて含む)/ `sw.js` / `manifest.webmanifest` / `icon-*.png`

## タイマーの仕組み

動作中のタイマーは「完了予定の時刻」を基準に残り時間を計算します(1秒ごとに減らす方式ではありません)。

- タブが裏に回って処理が間引かれても、端末がスリープしても、戻った時点で正しい残り時間になります。
- 更新の合図には Web Worker を使い、裏タブでも終了をなるべく遅れずに検知します。
- 状態は `localStorage`(`pomo_timer_v1`)にも保存するので、再読み込みやタブの破棄の後も続きから再開できます。複数のタブで開いても、記録は1回だけです。

席を外していて終了を遅れて検知したときの扱い:

| 状況 | 動作 |
| --- | --- |
| 集中が終わってから1時間以内(1時間より長い設定のときは、その1フェーズ分以内)に検知 | 集中を記録します。自動開始が有効なら、休憩は本来の終了時刻から数えます(休憩まで終わっていれば、次の集中を待ちます)。 |
| 休憩が終わってから90秒を超えて検知 | 次の集中は自動で始めません(席にいなかった時間を集中として記録しないため)。 |
| 上の時間を超えて放置 | 記録せずにリセットします(スリープや放置で、実際には学習していない記録が残らないように)。 |

通知音・通知は、終了から90秒以内に検知できたときだけ出します。ブラウザが完全に停止する環境(スマホをロックした iPhone など)では、アプリに戻った時点で上記の扱いになります。

## データ

すべて `localStorage` に保存されます(ブラウザのデータを消すと失われます。CSV書き出しでバックアップできます)。

| キー | 内容 |
| --- | --- |
| `pomo_log_v1` | 日ごとの記録 `{ "YYYY-MM-DD": { minutes, sets, subjects: { 科目: 分 } } }` |
| `pomo_tasks_v1` | タスクの配列 `{ id, name, est, done_pomos, done, active }` |
| `pomo_settings_v2` | 設定(集中・休憩の長さ、長い休憩までの回数、自動開始、目標、科目) |
| `pomo_timer_v1` | タイマーの状態(モード、サイクル、完了予定時刻など) |

CSV は UTF-8(BOM付き)で、Excel でも日本語がそのまま開けます。

## 対応ブラウザ

最近のブラウザ(Chrome / Edge 111+、Safari / iOS 16.4+、Firefox 128+ が目安)。次の機能を使っています: `@property`、`color-mix()`、`<dialog>`、コンテナクエリ単位、`dvh`。

- 通知: 初回のスタート操作時に許可を求めます(設定画面からも許可できます)。Android の Chrome などでは Service Worker 経由で表示します。
- 小窓: Document Picture-in-Picture に対応した Chrome / Edge のみ(非対応のブラウザではボタンを表示しません)。
